# 노트 — 태블릿용 손글씨 필기 앱

굿노트(GoodNotes)처럼 펜으로 필기하는 웹 앱입니다. 아이패드(Safari), 갤럭시 탭(Chrome·삼성 인터넷), PC 브라우저에서 모두 쓸 수 있고, 홈 화면에 추가하면 일반 앱처럼 전체 화면으로 열리며 인터넷 없이도 동작합니다.

설치할 것도, 빌드할 것도 없습니다. 이 폴더를 그대로 웹에 올리면 됩니다.

## 주요 기능

| 구분 | 기능 |
| --- | --- |
| 필기 | 필압에 따라 굵기가 바뀌는 펜, 형광펜(글씨 아래로 비치는 방식), 펜 색 5개·굵기 3개를 저장해 두고 바로 바꾸기 |
| 지우기 | 부분 지우개(지나간 곳만 지움) / 획 지우개(획 전체를 지움), 크기 3가지 |
| 도형 보정 | 선을 긋고 펜을 잠깐 멈추면 직선·원·사각형·삼각형으로 반듯하게 바뀜 |
| 올가미 | 둘러 그려서 고르기, 눌러서 하나 고르기 → 옮기기, 모서리로 크기 바꾸기, 잘라내기·복사·붙여넣기·복제·색 바꾸기·삭제 |
| 글상자·사진·동영상 | 글자 입력(키보드 또는 Apple Pencil 손글씨 입력), 사진 넣기, 동영상 넣기(20MB까지, 누르면 재생) |
| 페이지 | 빈 종이·줄 노트·모눈·점 격자·코넬 노트·오선지, 흰색·아이보리·어두운 종이, A4 세로·가로·와이드 |
| 페이지 관리 | 페이지 목록(썸네일), 추가·복제·순서 바꾸기·삭제, 서식 바꾸기(한 페이지 또는 전체) |
| PDF | PDF를 가져와서 그 위에 필기, 필기한 노트를 PDF로 내보내기 |
| 백업 | 노트를 `.gnote` 파일로 내보내고 다른 기기에서 가져오기 |
| 저장 | 쓰는 즉시 기기에 자동 저장, 실행 취소·다시 실행 |
| 클라우드 | 내 구글 시트·드라이브에 저장, 여러 기기 동기화, 손글씨 검색, 학생 노트 제출·모아 보기 |
| 과제 | 문제지 만들기(AI 문제 만들기), 반에 과제 내주기, 낱말·AI 초안 검사, 피드백·첨삭 돌려주기 |

## 태블릿 사용법

- **펜**: 그리기. 펜을 한 번이라도 쓰면 손가락은 자동으로 화면 이동·확대 전용이 됩니다(손바닥이 닿아도 그려지지 않음). 도구 막대 오른쪽 끝 손 모양 버튼으로 손가락 그리기를 다시 켤 수 있습니다.
- **손가락 한 개**: 화면 이동 (펜이 없을 때는 그리기)
- **손가락 두 개 벌리기·오므리기**: 확대·축소
- **손가락 두 개로 톡**: 실행 취소 / **세 개로 톡**: 다시 실행
- **펜 옆 버튼(S펜)·지우개 끝(서피스 펜 등)**: 누른 채로 쓰면 지우개
- 색이나 굵기 버튼을 **한 번 더 누르면** 그 칸의 색·굵기를 바꿀 수 있습니다.

키보드 단축키(아이패드 키보드·PC): `⌘/Ctrl+Z` 실행 취소, `⌘/Ctrl+Shift+Z` 다시 실행, `⌘/Ctrl+C·X·V·D` 복사·잘라내기·붙여넣기·복제, `Delete` 삭제, `P` 펜, `H` 형광펜, `E` 지우개, `L` 올가미, `T` 글상자, `⌘/Ctrl+0` 폭에 맞추기, 스페이스바를 누른 채 끌기로 화면 이동.

## 앱처럼 설치하기

웹에 올린 주소로 접속한 뒤:

- **아이패드**: Safari에서 공유 버튼 → **홈 화면에 추가**
- **갤럭시 탭**: Chrome 메뉴(⋮) → **앱 설치** 또는 **홈 화면에 추가** / 삼성 인터넷 메뉴 → **현재 페이지 추가 → 홈 화면**

## 웹에 올리기 (GitHub Pages, 무료)

1. 이 저장소의 **Settings → Pages**로 갑니다.
2. **Build and deployment**에서 Source를 **Deploy from a branch**로, Branch를 이 코드가 있는 브랜치와 `/ (root)`로 고르고 저장합니다.
3. 1~2분 뒤 `https://<깃허브 아이디>.github.io/goodnotes/` 주소로 열립니다.

펜 입력과 오프라인 저장은 `https` 주소에서만 제대로 동작합니다. GitHub Pages, Netlify, Vercel 같은 곳은 모두 https입니다.

## 내 컴퓨터에서 실행하기

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 열기
```

파일을 더블클릭해서(`file://`) 열면 동작하지 않습니다. 꼭 위처럼 간단한 서버로 여세요.

## 클라우드 (구글 시트·드라이브) 연결

구글 Apps Script로 내 구글 드라이브를 저장소로 씁니다. 별도 서버나 비용이 없습니다. 설치 방법은 앱의 `setup.html`(첫 화면 구름 버튼 → “주소를 만드는 방법 보기”)에 그림 없이도 따라 할 수 있게 정리해 두었습니다.

- **혼자 쓰기**: 여러 기기에서 같은 노트를 쓰고, 손글씨를 검색합니다 (검색창에 쓰고 Enter).
- **수업에서 쓰기**: 선생님이 한 번 설치하고 반마다 초대 링크를 보내면 (한 저장소에 여러 반을 둘 수 있습니다), 학생은 이름만 넣고 씁니다. 학생 노트는 닫을 때마다 제출되고, 선생님은 구글 시트(학생 이름·PDF 링크·손글씨 글자)와 앱에서 모아 봅니다. 학생은 자기 노트만 볼 수 있습니다.
- **과제**: “문제지 만들기”(직접 쓰거나 AI로 문제 만들기) 또는 PDF 활동지를 반에 내주면, 학생 앱 맨 위 “받은 과제”에 뜹니다. 문제지는 그림으로 굳혀 보내므로 학생이 지울 수 없습니다.
- **초안 검사**: 제출하면 시트에 핵심 낱말 확인 결과가 적히고, 시트 'AI 설정' 탭에 키(Gemini 무료, ChatGPT·Claude 유료)를 넣으면 AI 피드백 초안도 적힙니다.
- **돌려주기**: 시트 '노트' 탭 “선생님 피드백” 칸에 쓰거나, 앱에서 학생 노트를 열어 펜으로 첨삭하고 “돌려주기”를 누르면 학생 앱에 “새 피드백”으로 갑니다.
- 손글씨 검색은 구글 드라이브의 무료 글자 인식(OCR)을 씁니다.

서버 코드는 `apps-script/Code.gs` 하나입니다.

## 데이터는 어디에 저장되나요?

클라우드에 연결하지 않으면 노트는 **그 기기의 그 브라우저 안**(IndexedDB)에만 저장되고 어디로도 보내지 않습니다. 그래서:

- 다른 기기로 옮길 때는 노트 메뉴 → **백업 파일로 내보내기**로 `.gnote` 파일을 만든 뒤, 다른 기기에서 **가져오기**를 하세요.
- 브라우저의 "방문 기록 및 사이트 데이터 지우기"를 하면 노트도 지워집니다. 중요한 노트는 가끔 백업하세요.
- 아이패드에서 Safari로 쓰던 노트와 홈 화면 앱으로 쓰던 노트는 서로 다른 저장 공간입니다. 한쪽으로 정해서 쓰는 것을 권합니다.

## 파일 구성

```
index.html              앱 화면의 뼈대
manifest.webmanifest    홈 화면 설치 정보
sw.js                   오프라인 동작(서비스 워커)
css/app.css             화면 디자인 (밝은·어두운 모드)
js/main.js              시작점, 화면 전환
js/library.js           노트 목록 화면
js/editor.js            편집 화면(도구 막대, 페이지 목록, 메뉴)
js/view.js              캔버스, 펜·손가락 입력, 확대·이동, 도구 동작
js/ink.js               획 모양 계산, 지우개 판정, 도형 인식
js/render.js            종이 서식·획·글자·사진 그리기
js/pdf.js               PDF 가져오기·내보내기
js/backup.js            백업 파일
js/cloud.js             클라우드 동기화·검색 (Apps Script와 주고받기)
js/cloud-ui.js          클라우드 연결 창, 검색 결과 화면
js/tasks.js             문제지 만들기, 과제 내주기, 피드백 돌려주기·받기
apps-script/Code.gs     구글 Apps Script 서버 코드 (시트·드라이브·글자 인식)
setup.html              클라우드 설치 안내
js/db.js                기기 저장소(IndexedDB)
vendor/pdfjs/           PDF 읽기 라이브러리(Mozilla pdf.js, Apache-2.0)
```
