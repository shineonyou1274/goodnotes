1. 구글 시트와 Apps Script 만들기

  1. 새 구글 시트를 만들고 이름을 노트 앱 저장소로 바꿉니다.
  2. 시트 위쪽 메뉴에서 확장 프로그램 → Apps Script를 누릅니다.
  3. 열린 편집기의 Code.gs에 있는 내용을 모두 지우고, 아래 코드를 복사해 붙여 넣습니다.

2. 비밀번호와 수업 코드 정하기

붙여 넣은 코드 맨 위의 세 줄을 바꿉니다.

  • OWNER_KEY: 나만 아는 관리자 비밀번호 (8자 이상). 학생에게 알려 주면 안 됩니다.
  • CLASS_CODE: 학생에게 알려 줄 수업 코드 (예: suhak-2-3). 혼자 쓸 때는 '' 그대로 둡니다.
  • CLASS_NAME: 학생 화면에 보일 수업 이름 (예: '2학년 3반 수학')

Ctrl/⌘ + S로 저장합니다.

3. 글자 인식(OCR) 켜기

  1. 편집기 왼쪽의 서비스 옆 +를 누릅니다.
  2. 목록에서 Drive API를 고르고 추가를 누릅니다.
  3. 편집기 위쪽 함수 목록에서 설치확인을 고르고 실행을 누릅니다.
  4. 권한 승인 창이 뜨면 내 계정을 고릅니다. "Google에서 확인하지 않은 앱" 화면이 나오면 고급 → (안전하지 않은 페이지로) 이동을 누르고 허용합니다. 내가 만든 스크립트가 내 드라이브와 시트를 쓰겠다는 뜻입니다.
  5. 아래 실행 로그에 준비 완료!가 나오면 성공입니다. 시트에 노트, 페이지 글자 탭이 생깁니다.

4. 웹 앱으로 배포하기

  1. 오른쪽 위 배포 → 새 배포를 누릅니다.
  2. 톱니바퀴(유형 선택)에서 웹 앱을 고릅니다.
  3. 다음 사용자 인증 정보로 실행: 나, 액세스 권한이 있는 사용자: 모든 사용자로 정하고 배포를 누릅니다.
  4. 나오는 웹 앱 URL(https://script.google.com/macros/s/…/exec)을 복사합니다.
“모든 사용자”로 해야 태블릿 앱이 주소에 접속할 수 있습니다. 대신 비밀번호(OWNER_KEY)나 수업 코드가 없으면 아무것도 볼 수 없고, 학생은 자기 노트만 볼 수 있습니다.

5. 노트 앱에 연결하기

  1. 노트 앱 첫 화면 오른쪽 위의 구름 버튼을 누릅니다.
  2. 내 저장소 (관리자)를 고르고, 웹 앱 주소와 관리자 비밀번호를 넣고 연결합니다.
  3. 다른 기기(아이패드, 갤럭시 탭, PC)에서도 똑같이 연결하면 노트가 서로 맞춰집니다.

6. (수업) 학생 초대와 노트 보기

  1. 구름 버튼 → 학생 초대 링크 복사를 눌러 학생들에게 보냅니다 (클래스룸, 메신저 등).
  2. 학생은 링크를 열고 이름(학번과 함께)만 넣으면 됩니다. 학생이 쓴 노트는 닫을 때마다 자동으로 제출됩니다.
  3. 학생 노트를 보는 방법은 세 가지입니다.
    • 구글 시트 “노트” 탭: 학생 이름, 노트 제목, 수정 시각, PDF 링크, 손글씨를 읽은 글자가 한 줄씩 적힙니다.
    • 구글 드라이브 “노트 앱 저장소/PDF/학생 이름” 폴더: 학생별 PDF
    • 노트 앱의 구름 버튼: 학생별 목록에서 열기를 누르면 내 기기에 사본으로 받아 펜으로 보고 표시할 수 있습니다.
  4. 노트 앱 검색창에 낱말을 쓰고 Enter를 누르면 모든 학생의 손글씨에서 찾습니다.
학생이 기기를 바꾸면 처음 기기의 구름 버튼 → 다른 기기에서 이어 쓰기 링크를 새 기기에서 열면 됩니다. 이 링크가 없으면 같은 이름이라도 다른 학생으로 다뤄서 예전 노트를 받을 수 없습니다 (다른 학생이 이름만 바꿔 남의 노트를 보지 못하게 하려는 것입니다).

알아 두기

  • 손글씨 인식은 구글 드라이브의 무료 글자 인식을 씁니다. 또박또박 쓴 글씨는 잘 읽고, 휘갈긴 글씨나 수식은 틀릴 수 있습니다.
  • 노트를 닫거나 지금 동기화를 누를 때 올라갑니다. 방금 쓴 내용은 올라간 뒤에 검색됩니다.
  • 코드를 고쳤다면 배포 → 배포 관리 → 연필(수정) → 버전: 새 버전 → 배포를 해야 반영됩니다. 이렇게 하면 웹 앱 주소는 그대로입니다.
  • 학생 개인정보(이름·손글씨)가 선생님의 구글 드라이브에 저장됩니다. 학교의 개인정보 지침을 확인하고, 이름 대신 번호만 쓰게 해도 됩니다.
  • 구글 무료 계정의 Apps Script는 한 번 실행에 6분까지만 쓸 수 있습니다. 쪽수가 아주 많은 PDF는 손글씨 읽기가 여러 번에 나눠 진행됩니다.
