클라우드(구글 시트·드라이브) 연결 안내

노트를 내 구글 드라이브에 저장하고, 손글씨를 검색하고, 학생 노트를 모아 보는 기능입니다. 처음 한 번만 10분 정도 설정하면 됩니다.

코드는 고칠 필요가 없습니다. 붙여 넣기만 하면 되고, 비밀번호와 반 목록은 구글 시트의 “설정” 탭에서 칸에 적기만 하면 됩니다.

1. 구글 시트에 코드 붙여 넣기

  1. 새 구글 시트를 만들고 이름을 노트 앱 저장소로 바꿉니다.
  2. 시트 위쪽 메뉴에서 확장 프로그램 → Apps Script를 누릅니다.
  3. 열린 편집기의 Code.gs에 있는 내용을 모두 지우고, 아래 코드를 복사해 붙여 넣은 뒤 Ctrl/⌘ + S로 저장합니다. 코드는 고치지 않습니다.
코드를 불러오는 중…

2. 설치 확인 (권한 승인)

  1. 편집기 위쪽 함수 목록에서 설치확인을 고르고 실행을 누릅니다.
  2. 권한 승인 창이 뜨면 내 계정을 고릅니다. “Google에서 확인하지 않은 앱” 화면이 나오면 고급 → (안전하지 않은 페이지로) 이동을 누르고 허용합니다. 내가 만든 스크립트가 내 드라이브와 시트를 쓰겠다는 뜻입니다.
  3. 아래 실행 로그에 준비 완료!가 나오면 성공입니다.
로그에 “글자 인식을 쓸 수 없습니다”가 나오면: 편집기 왼쪽 서비스 옆 + → Drive API → 추가를 누른 뒤 다시 실행하세요.

3. 웹 앱으로 배포하기

  1. 오른쪽 위 배포 → 새 배포를 누릅니다.
  2. 톱니바퀴(유형 선택)에서 웹 앱을 고릅니다.
  3. 다음 사용자 인증 정보로 실행: 나, 액세스 권한이 있는 사용자: 모든 사용자로 정하고 배포를 누릅니다.
“모든 사용자”로 해야 태블릿 앱이 접속할 수 있습니다. 그래도 비밀번호나 수업 코드가 없으면 아무것도 볼 수 없고, 학생은 자기 노트만 볼 수 있습니다.

4. 시트의 “설정” 탭 채우기

  1. 구글 시트로 돌아가 새로 고침하면 맨 앞에 설정 탭이 있고, 메뉴에 노트 앱이 생깁니다.
  2. 관리자 비밀번호는 자동으로 만들어져 있습니다. 그대로 써도 되고, 8자 이상으로 바꿔도 됩니다. 학생에게 알려 주면 안 됩니다.
  3. (수업에서 쓸 때) 6번째 줄부터 반 이름 칸에 반을 한 줄에 하나씩 적습니다. 예: 2학년 3반 수학, 2학년 4반 수학. 수업 코드는 자동으로 채워집니다.
  4. 메뉴에서 노트 앱 → 초대 링크 만들기를 누르면 관리자 연결 링크와 반별 학생 초대 링크가 채워집니다.

반은 언제든 줄을 더하거나 지워서 바꿀 수 있습니다. 다시 배포할 필요가 없습니다. 반 이름을 지우면 그 반 학생은 더 이상 제출할 수 없지만, 이미 낸 노트는 남아 있습니다.

5. 내 태블릿 연결하기

  1. “설정” 탭의 관리자 연결 링크를 내 태블릿(또는 PC)에서 엽니다. 메일이나 메신저로 나에게 보내서 열면 편합니다.
  2. 노트 앱이 열리고 연결 창이 뜨면 관리자 비밀번호만 넣고 연결합니다.
  3. 다른 기기에서도 같은 링크로 연결하면 노트가 서로 맞춰집니다.

6. (수업) 학생 초대와 노트 보기

  1. “설정” 탭의 반별 학생 초대 링크를 그 반 학생들에게 보냅니다 (클래스룸, 메신저 등). 노트 앱의 구름 버튼에도 반별 초대 링크 버튼이 있습니다.
  2. 학생은 링크를 열고 이름(학번과 함께)만 넣으면 됩니다. 학생이 쓴 노트는 닫을 때마다 자동으로 제출됩니다.
  3. 학생 노트를 보는 방법은 세 가지입니다.
    • 구글 시트 “노트” 탭: 반, 학생 이름, 노트 제목, 수정 시각, PDF 링크, 손글씨를 읽은 글자가 한 줄씩 적힙니다. 시트의 필터로 반별로 볼 수 있습니다.
    • 구글 드라이브 “노트 앱 저장소/PDF/반/학생 이름” 폴더: 반별·학생별 PDF
    • 노트 앱의 구름 버튼: 반을 골라 학생별 목록에서 열기를 누르면 내 기기에 사본으로 받아 펜으로 보고 표시할 수 있습니다.
  4. 노트 앱 검색창에 낱말을 쓰고 Enter를 누르면 모든 학생의 손글씨에서 찾습니다.
학생이 기기를 바꾸면 처음 기기의 구름 버튼 → 다른 기기에서 이어 쓰기 링크를 새 기기에서 열면 됩니다. 이 링크가 없으면 같은 이름이라도 다른 학생으로 다뤄서 예전 노트를 받을 수 없습니다 (다른 학생이 이름만 바꿔 남의 노트를 보지 못하게 하려는 것입니다).

알아 두기

  • 손글씨 인식은 구글 드라이브의 무료 글자 인식을 씁니다. 또박또박 쓴 글씨는 잘 읽고, 휘갈긴 글씨나 수식은 틀릴 수 있습니다.
  • 노트를 닫거나 지금 동기화를 누를 때 올라갑니다. 방금 쓴 내용은 올라간 뒤에 검색됩니다.
  • 나중에 새 버전의 코드로 바꿀 때는 코드를 붙여 넣은 뒤 배포 → 배포 관리 → 연필(수정) → 버전: 새 버전 → 배포를 누릅니다. 이렇게 하면 링크가 그대로 유지됩니다. “설정” 탭의 비밀번호와 반 목록도 그대로 남습니다.
  • 학생 개인정보(이름·손글씨)가 선생님의 구글 드라이브에 저장됩니다. 학교의 개인정보 지침을 확인하고, 이름 대신 번호만 쓰게 해도 됩니다.
  • 구글 무료 계정의 Apps Script는 한 번 실행에 6분까지만 쓸 수 있습니다. 쪽수가 아주 많은 PDF는 손글씨 읽기가 여러 번에 나눠 진행됩니다.
