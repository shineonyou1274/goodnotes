코드는 사본에 이미 들어 있어 붙여 넣을 필요가 없습니다. 비밀번호는 시트 설정 탭 B1 칸에 있습니다.

🚫

코드를 바꿀 때 “새 배포”는 누르지 마세요 가장 중요

새 배포를 하면 주소가 바뀌어 학생 링크가 모두 끊깁니다.

배포 ▾→새 배포❌
배포 ▾→배포 관리→✏→버전: 새 버전→배포✅

새 배포는 맨 처음 설치할 때 한 번만 합니다 (웹 앱, 액세스 모든 사용자).

🔗 학생 초대: ☁️ 구름 → 반 초대 링크 복사해 보내기

✏️ 피드백: ☁️ 구름 → 학생 줄 피드백 (또는 시트 학생 제출 탭 노란 칸)

🤖 AI 검사(선택): 시트 AI 설정 탭 B1에 키

연결이 안 될 때
  • “비밀번호를 … 바꿔 주세요” → 설정 탭 비밀번호를 영문+숫자 8자 이상으로
  • “서버에 연결하지 못했습니다” → 웹 앱 주소를 새 탭에서 열어 “노트 앱 서버가 동작 중”이 보이는지 확인. 안 보이면 배포 관리에서 /exec 주소를 다시 복사
  • 코드를 바꿨는데 그대로면 → 위의 배포 관리 → ✏ → 새 버전을 했는지 확인
  • 학교(교육청) 계정은 막혀 있을 수 있으니 개인 Gmail로 만드세요

손글씨 읽기(OCR)는 구글 드라이브 기능

제출한 페이지를 그림으로 만들어 드라이브에서 구글 문서로 변환하면, 구글이 글자를 읽어 줍니다. 읽은 글자로 손글씨 검색과 핵심 낱말 확인을 합니다.

무료이고 따로 가입할 것이 없지만, 흘려 쓴 글씨나 수식은 약합니다. 그래서 채점과 피드백은 AI가 답안 그림을 직접 보고 합니다.
