클라우드 연결 (처음 한 번)

필기만 할 거라면 이 설정은 필요 없습니다. 동기화·손글씨 검색·학생 노트 모아 보기를 쓸 때만 하세요.

1. 선생님: 설치 (PC에서 10분)

  1. 새 구글 시트 → 메뉴 확장 프로그램 → Apps Script
  2. 코드 칸을 비우고(Ctrl+A → Delete) 한 것을 붙여 넣기 → Ctrl+S
  3. 위쪽에서 설치확인 고르고 실행 → 권한 허용
    (“확인하지 않은 앱”이 나오면 고급 → 이동 → 허용)
  4. 배포 → 새 배포 → 웹 앱, 액세스 권한 모든 사용자 → 배포
  5. 시트의 설정 탭에서 비밀번호를 8자 이상으로 정하고, 반 이름을 적기

2. 선생님: 내 태블릿 연결

  1. 노트 앱 첫 화면 오른쪽 위 구름 버튼
  2. 내 저장소 (관리자) → 웹 앱 주소(…/exec)와 비밀번호 → 연결
  3. 연결되면 구름 버튼에 반별 초대 링크가 생깁니다 → 학생에게 보내기

3. 학생

  1. 선생님이 보낸 초대 링크 열기 → 이름(학번 이름) → 연결
  2. 노트에 쓰고 왼쪽 위 ← 누르기 → 자동 제출 (제출됨 표시)

선생님은 시트의 노트 탭(PDF 링크)이나 앱의 구름 버튼에서 학생 노트를 봅니다. 검색창에 낱말 + Enter로 손글씨도 찾습니다.

연결이 안 될 때
  • “비밀번호를 8자 이상으로” → 설정 탭 비밀번호를 8자 이상(영문+숫자)으로
  • “서버에 연결하지 못했습니다” → 웹 앱 주소를 새 탭에서 열어 보기. “노트 앱 서버가 동작 중”이 보여야 정상. 안 보이면 배포 → 배포 관리에서 /exec 주소를 다시 복사
  • 코드를 고칠 때는 새 배포 말고 배포 관리 → 연필 → 새 버전 (주소가 그대로 유지됨)
  • 학교 계정은 막혀 있을 수 있으니 개인 Gmail로 만드세요
