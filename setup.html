클라우드 연결

필기만 할 거면 필요 없습니다. 학생 노트를 모아 보거나 손글씨를 검색할 때만 하세요.

선생님 (PC에서, 처음 한 번)

  1. 새 구글 시트 → 확장 프로그램 → Apps Script
  2. 코드 칸 비우기(Ctrl+A → Delete) → → 붙여 넣기 → Ctrl+S
  3. 설치확인 고르고 실행 → 허용
  4. 배포 → 새 배포 → 웹 앱, 액세스 모든 사용자 → 배포 → 웹 앱 주소 복사
  5. 시트 설정 탭: 비밀번호를 영문+숫자 8자 이상으로 (예: note2026ok), 반 이름 적기
  6. 노트 앱 구름 버튼 → 내 저장소 → 주소와 비밀번호 넣고 연결. 끝!
⚠ 새 배포는 처음 한 번만. 다시 하면 주소가 바뀌어 학생 링크가 끊깁니다.
코드를 바꿀 때는 배포 관리 → ✏ → 새 버전.

학생에게 보내기

구름 버튼의 반별 초대 링크를 복사해 보내세요. 학생은 링크 열고 이름 쓰고, 노트를 쓴 뒤 제출하기만 누르면 됩니다.

학생 노트는 시트의 노트 탭(PDF 링크)이나 앱의 구름 버튼에서 봅니다.

과제 내주고 검사하기

  1. 앱 첫 화면 문제지 만들기 (PDF 활동지는 가져오기) → 위쪽 과제로 내주기
  2. 학생은 맨 위 받은 과제를 눌러 쓰고 제출하기
  3. 시트 노트 탭 선생님 피드백 칸에 쓰면 학생에게 갑니다. 앱에서 학생 노트를 열고 빨간 펜으로 고친 뒤 돌려주기도 됩니다.
  4. 루브릭(선택): 과제를 내줄 때 기준과 배점을 정하면, 돌려주기 창에서 점수를 누르고 피드백을 만듭니다.
  5. AI 검사(선택): 시트 AI 설정 탭에 키 넣기. 받는 방법은 그 탭에 있습니다.

이미 설치했다면: 새 코드를 붙여 넣고 배포 관리 → ✏ → 새 버전. 시트를 새로 고치면 탭이 생깁니다.

연결이 안 될 때
  • “비밀번호를 … 바꿔 주세요” → 설정 탭 비밀번호를 영문+숫자 8자 이상으로
  • “서버에 연결하지 못했습니다” → 웹 앱 주소를 새 탭에서 열어 보기. “노트 앱 서버가 동작 중”이 보여야 정상. 안 보이면 배포 → 배포 관리에서 /exec 주소를 다시 복사
  • 학교 계정은 막혀 있을 수 있으니 개인 Gmail로 만드세요
